# Simulador Gráfico de Autómatas Finitos

Proyecto desarrollado para el Parcial del Segundo Corte de Teoría de la Computación[cite: 1]. Consiste en una aplicación gráfica web interactiva local para la conversión de autómatas, obtención de expresiones regulares y verificación de equivalencia[cite: 1, 2].
